# GATE BLASTER — WebGL v9 DANGER ZONE

WebGL 2で独自3Dモデルを描画する、iPhone Safari・PC向けの群衆シューティングゲーム。

**プレイ:** https://aries1a.github.io/gate-blaster/

## v9: 大群に見合う耐久力＆接触リスク

- 雑魚の集団HPを、実際の兵士数に連動させた。ステージ1の最初の84人集団はHP約125→1,218に上昇。
- ボス戦中に追加される雑魚のHPも実人数に合わせて増加。
- 部隊が最後の1人でも敵に接触した場合は倒される。接触がない場合に人数を減らすことはない。
- 接触した兵士の人数に応じて部隊HPにも被害が発生。

## v8: 大群＆攻城戦

- 雑魚1集団の人数をv7比で**約7倍**に増量。通常のステージに追加の18ウェーブを配置し、集団のHPも上昇。
- ボス戦中は接近中・近距離戦のどちらでも、複数レーンに雑魚が継続して出現する。
- ボスは登場した瞬間からダメージを受ける。武器や支援ヘリ・砲台で遠距離から削れる。
- ボスHPをステージ1で **11,600** に変更（v7の1,580に対して約7.3倍）。以降はステージに応じて増加。
- iPhone負荷対策として、遠くの雑魚は簡略化された3D形状で描画し、非常に大きい集団は表示モデル数を抑える。画面上の `×N` は残存人数を示し、接触判定には実際の集団人数を反映する。

## 操作と成長

- 指で左右にドラッグ、PCでは左右キーなどで部隊を動かす。主武器の弾は前方へ直進し、支援兵器が自動攻撃する。
- 敵に実際に接触した隊員が減少する。人数を増やすと火力だけでなく接触リスクも上がる。
- ボスは近づいてパンチを繰り返す。被弾すると部隊とHPが大きく減少する。
- クリア後はランダムな3択から永続ではないラン中の強化を1つ選び、次のステージに持ち越す。
- オリジナルのWeb AudioシンセBGMと効果音は画面の♫ボタンからオン・オフ可能。

## 技術とライセンス

HTML・CSS・JavaScriptは `index.html` に格納。WebGL 2・Canvas 2Dを使用し、外部ライブラリ、画像、音楽ファイルは使用していません。最高到達ステージはブラウザのlocalStorageに保存されます。現時点でオープンソースライセンスは設定していません。
