# GATE BLASTER

iPhone（Safari）・PCのブラウザで遊べる、1ファイル完結型のゲートシューティングゲームです。

## 遊び方

- iPhone：画面上で指を左右にドラッグ。射撃は自動です。
- PC：マウスの移動または左右キー（A/Dも可）。Pキーで一時停止。
- ゲートで仲間を増やし、武器ボックスを撃って強化し、ボスを倒してください。
- ステージクリア後は強化を選び、次のステージに挑戦できます。

## GitHub Pages

このリポジトリの `main` ブランチの `/(root)` を Pages の公開元に設定すると、
`https://<GitHubユーザー名>.github.io/gate-blaster/` で公開できます。

HTMLとJavaScriptは `index.html` に含まれており、外部ライブラリや外部画像・音源は使用していません。
画面表示にはOS標準のフォント・絵文字、音にはWeb Audio APIを使用します。
進捗の最高ステージは端末のブラウザのlocalStorageに保存されます。
