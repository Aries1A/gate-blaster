# GATE BLASTER — WebGL v7 ROGUE RUSH

WebGL 2で独自3Dモデルを描画する、iPhone Safari・PC向けの群衆シューティングゲーム。

プレイ: https://aries1a.github.io/gate-blaster/

## v7の変更

- **直進射撃**: 主武器の弾は実体を持ち、前方（ワールドの -Z）へまっすぐ飛ぶ。敵を自動追尾しない。
- **兵士単位の接触判定**: 敵と実際に接触した兵士だけを失う。部隊を大きくすると火力と接触リスクがともに増える。
- **オリジナルBGM**: Web Audioで生成したシンセ曲。スタートで再生、♫ボタンで音楽と効果音を切替。外部音源は不使用。
- **接近型ボス**: 歩いてプレイヤーへ近づき、近距離で強烈なパンチを繰り返す。被弾すると部隊とHPを大きく失う。
- **クリア後の3択強化**: 初期人数・武器・火力・連射速度・最大HP・被害軽減・支援ヘリ・自動砲台の候補からランダムに3つ表示し、ひとつ選ぶ。選んだ強化は次のステージにも持ち越す。ゲームオーバーからリトライすると初期状態に戻る。
- v6からの支援ヘリ、砲台、ダメージ数字、コンボ、ボス演出、クリア紙吹雪を維持。

## 動作環境とライセンス

- `index.html` にHTML・CSS・JavaScriptを収録し、WebGL 2とCanvas 2Dを使用。
- 外部ライブラリ・画像・音楽ファイルは使用していません。
- 最高到達ステージはブラウザのlocalStorageに保存。
- 本リポジトリには現時点でオープンソースライセンスを設定していません。
