# GATE BLASTER — WebGL v5

iPhone（Safari）・PCブラウザ向けの、実際の3D描画によるオリジナル群衆シューティングゲームです。

公開先: https://aries1a.github.io/gate-blaster/

## 操作

- iPhone: 指で左右にスワイプ。射撃は自動。
- PC: 左右キー、またはマウスで左右に動かす。
- 青い+1ゲートを通って部隊を増やし、箱を壊して武器やドローンを獲得。
- 敵の群れと接触すると部隊人数が減少。
- 最後の巨大ボスは攻撃予告を表示し、増援を呼び、HPによって3段階で強化。

## 実装・ライセンス

- 単一の `index.html` にHTML、CSS、JavaScript、GLSLを収録。
- WebGL 2で3Dモデルを描画し、Canvas 2Dでゲーム内ラベルを描画。UIはHTML/CSS。
- 外部の画像・音源・ライブラリを使用せず、プリミティブ形状から独自に構築。
- このリポジトリには現時点でオープンソースライセンスを設定していません。
- 表示やゲーム進行にはWebGL 2対応ブラウザが必要です。
