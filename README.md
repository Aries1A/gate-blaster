# GATE BLASTER — WebGL v17 FEVER RUSH

iPhone Safari・PC向けの、WebGL 2による3D群衆シューティングゲーム。

**プレイ:** https://aries1a.github.io/gate-blaster/

## v17: FEVER RUSH + 箱の衝突 + BGM / SE

- **FEVERステージ:** ステージ3から4ステージごと（3、7、11、…）に発生。通常の出現予定はそのまま、追加の雑魚9群と宝箱8個が流れてくる。FEVERの追加箱は通常より少し開けやすく、武器・人数・ドローン・ヘリ・砲台の強化を狙える。ゲートや箱の回収手順は変わらない。
- **箱の衝突判定:** 未開封の箱に接触した味方は人数から減少する。実際の隊員配置と箱の幅・奥行きで判定し、箱1個につき衝突は1回。開封後の光るアイテムは安全で、触れると通常どおり取得。最後の隊員が箱にぶつかると敗北。
- **BGM:** 既存の小音量シンセを更新。通常／FEVER／ボスでテンポ・メロディ・ベースを変更し、キック・スネア・ハイハットを強化。外部音声ファイルなしでWeb Audio APIによるオリジナル音楽を生成。
- **SE:** 主武器の射撃、敵・箱・ボスへの着弾、箱の開封、アイテム取得、敵の撃破、FEVERの開始、ボス登場の音を追加。射撃や着弾は再生間隔に上限を設け、連続音が過剰にならないようにした。♫ / 🔇 ボタンでBGMとSEをまとめて切り替え。iPhoneはPLAY時の操作で音声を開始する。
- 普段のステージの敵・ボスHP、出現予定、宝箱HP、人数ゲートと強化選択の仕様は維持。

## v16: 最小限の文字で、プレイ画面を見やすく

- **HUD:** 人数・武器・HP・ステージをアイコンと数字で表示。進捗は細いバー、撃破エネルギーは小さいバーと3つの強化獲得ドットに集約。
- **常時説明の削減:** ステージルールは小さなアイコンのみ（補助情報はアイコンのタイトル属性）。ステージ名・操作ヒント・フッターの説明文をプレイ中から撤去。ヘリ・砲台・ドローン・司令官Lvは短い記号と数値で表示。
- **戦闘演出:** 中央通知を短い警告記号・数字に変更。通常の弾ダメージ数値は非表示、クリティカル時だけ数字を表示。ゲートは残り人数、箱は種類アイコンと残りHP、開いた箱は★で表示。
- **選択・メニュー:** 戦闘中の3択とクリア後の3択は、短い強化名と効果1行に簡略化。タイトル・ゲームオーバー・一時停止画面も最小限の文字に。
- v15の箱回収・1人ずつ人数ゲート、雑魚HP・ボスHP・攻撃間隔・成長・ステージルール・操作と音響は変更なし。

## v15: 上手く動けば「箱も、人数も」

- 人数ゲートと強化箱は左右の同じタイミングで登場し、片方を取得しても反対側は消えない。
- 人数ゲートは通過中に約0.14秒ごとに1人ずつ増加。短く通ると少人数、長く留まると多く獲得できる。
- 箱は一定量撃って開け、光るアイテムをそのレーンで回収。箱HPの火力連動調整を維持。
- 両方を取ることも可能だが、移動と射撃に時間を使うため、何を優先するか判断が必要。

## v13: ボスの遠距離砲撃とHP強化

- ボスは登場直後から**遠距離砲撃**を開始。プレイヤー部隊の現在位置に予告範囲が表示され、短い猶予の後に着弾します。撃破前にその範囲から横へ移動すると回避可能です。
- 遠距離砲撃は実際に爆風範囲内にいる隊員に応じて人数とHPを減らします。ボスの種類で予告範囲・速度・間隔・威力が異なります。
- 接近後は従来のボス別パンチに切り替わります。ボスは登場時点からダメージを受け、雑魚増援も継続します。
- **ボスHPをv12比で2.5倍**に引き上げ、ステージ1のHPは7,426 → **18,565**。雑魚の出現数、HP、撃破エネルギーの仕組みは据え置き。
- リトライ時には予告・遠距離砲撃の状態もリセットします。

## v12: 「撃つ・避ける・選ぶ」のゲームプレイを強化

- **雑魚撃破 → KILL ENERGY → ステージ中の3択強化。** 4、10、18エネルギー到達時、戦闘を一時停止して攻撃・防御・支援の3系統から1つずつ提示。連射、火力、一時的なオーバードライブ、隊員回復、HP回復、防御、ドローン・ヘリ・砲台が候補。選んだ強化は現在のステージ中有効で、ステージクリア後のラン中強化とは別。
- **敵の遠距離攻撃。** ガード型の雑魚がピンク色の弾を撃つ。弾はワールド空間を直進し、実際に触れた隊員のみ減る。CROSS FIREステージではランナーも遠距離攻撃。
- **ボスごとの回避パターン。** タイタンは標準パンチ、ビートルは狭い高速攻撃、クラッシャーは広く重い攻撃、ヒドラは左右交互の攻撃。攻撃範囲は床の警告で確認できる。
- **ステージごとの特殊ルール。** STANDARD / SPEED RUSH（敵が速い） / ARMORED ZONE（敵HPアップ、撃破エネルギー+1） / CROSS FIRE（敵の射撃が激しい）が4ステージ周期で変化。
- v11よりボスHPを約1.6倍へ引き上げ、通常雑魚HPも少し強化。ステージ1のボスはHP 7,426。雑魚の出現密度を無闇に7倍にはせず、回避・射撃・強化の判断で難しくした。

## v11から維持する要素

明るい4種類のステージ、4種類の雑魚モデル、4種類のボスモデル、光る直進弾、強化に合わせて屈強になる司令官アバター、着弾演出、コンボ、ヘリ・砲台の自動支援。ステージクリア後のラン中3択強化も維持。

## 操作・仕様

- iPhoneは左右スワイプ、PCは左右キーまたはマウスドラッグ。射撃は自動。♫ ボタンで合成BGMと効果音を切り替え。
- 雑魚との接触や敵弾で実際に触れた隊員が減り、最後の1人を失うとゲームオーバー。ボスは登場直後からダメージを受け、接近後はパンチを繰り返す。
- リトライ時にはウェーブ一覧・戦闘中の強化・ラン中の強化をリセット。同一ステージの出現予定が重複しない。
- HTML・CSS・JavaScriptは `index.html` に格納。WebGL 2とCanvas 2Dを使用し、外部ライブラリ・画像・音楽ファイルを使わない。最高到達ステージはlocalStorageに保存。
- 現時点でオープンソースライセンスは設定していません。
