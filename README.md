# GATE BLASTER — WebGL v11 HYPER PARADE

明るい3Dステージを駆け抜ける、iPhone Safari・PC向けの群衆シューティングゲーム。

**プレイ:** https://aries1a.github.io/gate-blaster/

## v11 の新要素

- ステージを明るく再デザイン。SUNNY HARBOR / SUNSET METRO / NEON GARDEN / CRYSTAL SKYWAY の4つのテーマをステージごとに切り替え。
- 直進弾をシアン・ゴールドの発光トレーサーで視認しやすくし、着弾火花を強化。
- 雑魚敵に4タイプ（grunt / runner / brute / guard）。色・装備・体格・集団HP・速度・人数に個性。
- ボスに4タイプ（MEGA TITAN / STORM BEETLE / IRON CRUSHER / AERO HYDRA）。モデル、接近挙動、増援編成、攻撃間隔を差別化。
- プレイヤー部隊の中心に司令官アバターを追加。装備・強化・ステージ進行に合わせて大きさとアーマー・装飾が段階的に変化。
- iPhoneで大群を表示するため、遠景の敵は簡略化し、見た目の描画数に上限を設定。接触判定には集団の残存人数を利用。

## 難易度・操作

- v10の難易度再調整を基準に、雑魚の通常ウェーブと追加6ウェーブ、ボスのステージ1 HP 4,700を維持。敵タイプによって集団のHP・速度・人数は変動。
- ボスは登場時からダメージを受け、近づくにつれてパンチを繰り返す。ボス戦でも雑魚増援が出現。
- 主武器の弾は前方へ直進。支援ヘリと砲台は自動攻撃。
- 敵と接触した隊員だけを失い、最後の1人も接触すればゲームオーバー。
- クリア後はランダムな3択から強化を1つ選んで次のステージへ。リトライ時は敵ウェーブとラン中の強化をリセット。
- iPhoneは左右スワイプ、PCは左右キーまたはマウスドラッグ。♫ ボタンでオリジナルシンセBGMと効果音を切り替え。

## 技術とライセンス

ゲーム本体は `index.html` に格納した単一HTML。WebGL 2とCanvas 2Dを使用。外部ライブラリ・画像・音楽ファイルは使用していません。最高到達ステージはブラウザのlocalStorageに保存します。現時点でオープンソースライセンスは設定していません。
