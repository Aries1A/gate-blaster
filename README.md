# GATE BLASTER — WebGL v6 OVERDRIVE

iPhone（Safari）・PC向けの、WebGL 2を使用したオリジナル3D群衆シューティングゲーム。

プレイ: https://aries1a.github.io/gate-blaster/

## 操作とゲーム内容

- iPhone: 指で左右にスワイプ。PC: 左右キー、またはマウス・ドラッグ。
- 射撃は自動。青い人数ゲートを通過して隊員を増やし、コンテナを撃って装備を強化。
- 🚁 **ATTACK HELI**: 支援ヘリを獲得すると自動でロケット攻撃。
- 🔧 **AUTO TURRET**: 自走砲台を獲得すると連続射撃で援護。
- 連続撃破でコンボ表示が上がり、コンボに応じて攻撃力も少し上昇。敵へのダメージ数字、クリティカル表示、被弾フラッシュ、パーティクル演出あり。
- ボス登場の警告、3段階フェーズ、敵増援、クリア時のコンフェティと結果パネルを追加。
- ♪ ボタンで効果音をオン・オフ可能（初期状態はオフ）。
- ステージをクリアすると次のステージへ進みます。

## 技術とライセンス

- `index.html` にHTML・CSS・JavaScriptをすべて含み、追加のライブラリ・画像・音源は使用していません。
- 3DモデルはWebGL 2の基本形状を使って描画。画面上のダメージ数字等にはCanvas 2D、操作用UIにはHTML/CSSを使用。
- 最高到達ステージはブラウザのlocalStorageに保存。
- 現時点でオープンソースライセンスは設定していません。公開コードの再利用条件を明示する場合は、所有者が別途LICENSEファイルを追加してください。
