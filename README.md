# GATE BLASTER

iPhoneのSafari・PCのブラウザで遊べる、1ファイル完結型のオリジナル群衆シューティングゲームです。

## 遊び方

- iPhone：画面上で指を左右にドラッグします。
- PC：ドラッグ、または左右の矢印キーで部隊を動かします。
- 射撃は自動です。射程に入った敵や武器コンテナを撃ちます。
- 青い「+1」階段に入ると、通過中に仲間が増えます。
- 武器コンテナを壊すと武器レベルや支援機などを獲得できます。
- 赤い敵を撃破できずに接触すると、部隊人数が減少します。
- 最後のボスを倒せばクリア。次のステージは敵が強くなります。

開始時の部隊は13人。強化を選ばずに進むとボス戦で苦戦するバランスです。

## GitHub Pages

このリポジトリの `main` ブランチの `/(root)` を Pages の公開元に設定します。

公開URL: https://aries1a.github.io/gate-blaster/

HTML・CSS・JavaScriptは `index.html` に含まれており、外部ライブラリや外部画像・音源は使用していません。
表示にはブラウザのCanvas 2D APIとOS標準フォント・絵文字を使用します。
最高到達ステージは端末のブラウザのlocalStorageに保存されます。
